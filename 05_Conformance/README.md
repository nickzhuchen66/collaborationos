# COS Manual Conformance

The M5A-M5D directories contain 126 synthetic JSON fixtures and four manual
conformance matrices.

| Wave | Focus |
|---|---|
| M5A | context and authority |
| M5B | evidence, decision, and cost |
| M5C | handoff, acceptance, failure, and takeover |
| M5D | learning and promotion boundaries |

Fixture references such as `cos:decision/COS-011` and
`cos:decision/COS-019` are stable synthetic fixture-local authority tokens.
They do not link to or disclose an internal governance record.

Use the [Manual Conformance Guide](../docs/gate-pack-v0.1/MANUAL_CONFORMANCE_GUIDE.md).
The fixtures are expected-fact examples, not an automated validator.
