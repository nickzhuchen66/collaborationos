## What this package is

This package is the operator-facing entry for:

- seven manual/static protocols, P01-P07;
- nine strict artifact schema/template pairs, A01-A09;
- 126 synthetic M5A-M5D fixtures;
- four manual conformance matrices.

It links to canonical public assets and does not copy or override them.

## What this package is not

This is not an automated validator, executable Skill, Workflow runtime, CLI,
SDK, agent framework, SaaS product, host connector, or production system. It
does not prove completed cross-host validation.

No document in this package authorizes execution, spending, host access,
acceptance, retry, promotion, canonical write, or production use.
